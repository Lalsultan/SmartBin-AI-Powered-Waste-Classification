# AI Waste Classification

A collaborative academic project that classifies waste images into six categories using transfer learning with MobileNetV2 and a TensorFlow/Keras classifier head. The notebook includes image preprocessing, data splitting, augmentation, evaluation, Arabic class labels, and an optional Gradio interface.

## Dataset

The notebook references the [Garbage Classification dataset on Kaggle](https://www.kaggle.com/datasets/asdasdasasdas/garbage-classification). The dataset is not included. Obtain it from the source and ensure its terms permit your intended use.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Place the authorized dataset in the path configured in the notebook.
4. Open `waste_classification.ipynb` in Jupyter and run the cells in order.

The notebook's optional Gradio demo is disabled by default. Model accuracy noted in the original coursework has not been independently reproduced in this cleaned draft.
